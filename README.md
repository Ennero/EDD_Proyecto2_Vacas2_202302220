## 📌 Descripción General

Este repositorio contiene la implementación y entrega de **🔗 Blockchain, Merkle Trees & AVL Tree Simulation (EDD)**, desarrollado en el curso de **Estructuras de Datos** en la Universidad de San Carlos de Guatemala.

- **Objetivo:** Simulación criptográfica de Blockchain con árboles Merkle, árboles AVL, árboles B y reportería en Python.
- **Stack Principal:** `Python`.
- **Área:** Ciencias de la Computación, Algoritmos y Desarrollo de Software.
